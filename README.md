JoyDeck Hub is the official desktop application for configuring and controlling the JoyDeck hardware device (ESP32-based intelligent joystick controller).
JoyDeck transforms a physical 8-way analog stick into a powerful desktop control system for automation, shortcuts, multimedia control, and productivity.

---

Main Features:
🎯 8 Programmable Directions
Each direction can be assigned to:
🖥 Open an application (.exe, .bat, URI)
🌐 Open a website (http / https)
⌨ Simulate keyboard shortcuts
🖱 Control the mouse
🎵 Spotify controller mode
🎬 Media controller mode
🌍 HTTP request (GET / POST)
⚙ System control (shutdown, lock, etc.)

---
RGB LED Feedback
Each command can be associated with a custom LED color.
Visual feedback helps you instantly recognize:
- Active direction
- Confirmed command
- Persistent modes
- Errors
  
---
First Setup
1️⃣ Flash the ESP32
Before using JoyDeck Hub, you must program the ESP32 firmware.
To do this:
👉 Use ESPprogrammer
Download it from the official repository.
ESPprogrammer allows you to:
- Flash JoyDeck firmware
- Configure device settings
- Manage ESP32 programming safely
  
---
2️⃣ Connect JoyDeck
Connect the device via USB
Launch JoyDeck Hub
Select the correct serial port
Click Connect
  
---
3️⃣ Configure Your Directions
Choose an action for each direction
Set LED colors
Test commands
Click Save
You're ready to go 🚀
