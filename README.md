# JoyDeckHub
JoyDeckHub is the companion desktop application for configuring and controlling the **JoyDeck** device.  
Built in Processing 4, it provides a modern, user-friendly interface for command assignment, color control, profile management, and advanced interaction modes.

---

## Features
- Complete command editor for 8 joystick directions
- Assignable actions:
  - Open application
  - Open URL
  - Simulate key presses
  - System commands (shutdown, lock, volume, etc.)
  - Media controller (next/prev/seek/volume)
  - Spotify controller
  - HTTP GET/POST
  - Mouse Mode (joystick → mouse cursor)
- Save & load configuration profiles (`.jdf`)
- Import/export config files
- Windows autostart manager
- Remote update support via GitHub RAW files
- Custom serial protocol communication
- Integrated debug log
- Polished GUI using enhanced Nimbus look-and-feel# JoyDeck
